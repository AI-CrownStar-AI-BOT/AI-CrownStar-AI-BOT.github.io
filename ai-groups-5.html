🌐 在线 API 与离线模型：灵活切换，永不中断

无论网络环境如何，CrownStar 始终为您提供 AI 服务

在现实中，网络连接并非总是可靠的 — 尤其是在内网环境、移动办公或特定行业（如金融、政府）场景下。CrownStar 同时支持在线 API 调用和本地离线模型运行，确保业务连续性。

双重模式的优势：

  • 在线模式：调用 DeepSeek API、OpenAI API 或其他云端模型，适合需要最新模型能力且网络稳定的场景。
  • 离线模式：使用您本地下载的模型（如 DeepSeek V1 Lite、Llama 3），完全不依赖互联网，适合内网环境或对数据隐私要求极高的场景。
  • 自动切换：CrownStar 可以配置为“在线优先，离线降级”，当 API 不可用时自动切换到本地模型，确保服务不中断。

对于政府机构和大型企业，离线模式是实现“数据不出域”合规要求的关键。对于经常出差或网络不稳定的用户，自动切换功能确保您随时随地都能获得 AI 帮助。
