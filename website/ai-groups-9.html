开源精神 + 商业可持续

CrownStar 的核心数学模块和 Egg Apex vLLM 项目已开源（MIT 协议）。而完整的 CrownStar 平台（包括 UI、API、记忆系统、互联网皮层等）以 商业源码授权 形式提供给付费用户。

源码包含什么？

◆ 完整的 Python 源代码（所有模块）。
◆ 数据库 Schema 和迁移脚本。
◆ 完整的 UI 前端代码（HTML/CSS/JS）。
◆ Docker 和 Kubernetes 部署配置。
◆ 详细的 API 文档和开发者指南。

如何获取源码？

购买 组织版（小型/中型/大型） 或 企业旗舰版 后，您将收到私有 GitHub 仓库的邀请。源码永久可访问，并可自由用于企业内部分发和修改。

自定义能力

◆ 修改 UI 界面和品牌标识（白标支持）。
