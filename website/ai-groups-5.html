在线 API 与离线模型

同时支持 DeepSeek API 和本地下载模型，灵活切换，满足不同场景需求。

两种模式，自由选择

◆ 在线 API 模式：使用 DeepSeek 官方 API（或任何 OpenAI 兼容 API）。适合需要最高性能、不想管理模型文件的用户。
◆ 离线模型模式：从 Hugging Face 下载模型到本地，完全离线运行。适合对数据隐私有严格要求的客户。

无缝切换

AI-Groups 允许您在同一会话中混合使用在线和离线模型。例如，您可以让 DeepSeek API 处理通用问题，同时让本地模型处理敏感数据。所有切换对用户完全透明。

数据隐私承诺

无论您选择哪种模式，您的数据永远不会被 CrownStar 收集或上传。在线 API 模式下，您的 API 密钥和请求内容由您完全控制；离线模式下，数据根本不会离开您的硬件。

🔒 最佳实践： 对于涉及商业机密、个人隐私或政府数据的场景，强烈建议使用离线模式。对于日常通用问答，在线 API 模式更便捷。
