📖 CrownStar API 文档

适用于源代码持有者（组织版及以上）的完整 RESTful API 参考

🔐 源代码用户专属

🚀 快速开始

CrownStar API 为组织版、企业版用户提供完整的程序化控制能力。 所有 API 均基于 HTTP + JSON，支持标准的 API Key 认证。

🔑 认证方式

在请求头中携带 X-API-Key 或使用 Authorization: Bearer <your_key>。

🌐 基础 URL

请将 https://your-crownstar-server.com 替换为您实际部署的 CrownStar 服务器地址。

# 示例请求
curl -X GET https://your-crownstar-server.com/api/v1/health \
  -H "X-API-Key: your_api_key_here"
📌 提示： 此 API 仅适用于 组织版（小型/中型/大型） 和 企业旗舰版 用户。 免费版、基础版、进阶版、专业版不提供完整 API 访问。

📋 API 端点参考

点击展开每个模块的详细端点说明。

💬 聊天与对话 ▼
POST /api/v1/chat
发送消息并获取 AI 回复（支持流式与非流式）
请求体 (JSON):
{ "message": "你好，请解释一下什么是主权 AI", "temperature": 0.85, "max_tokens": 512, "top_p": 0.95, "stream": false }
响应示例:
{ "id": "chat_123abc", "content": "主权 AI 是指数据主权、算法主权和计算主权完全由用户掌控的 AI 系统...", "tokens_used": 234, "model": "deepseek-v4" }
GET /api/v1/conversations
获取所有对话列表
GET /api/v1/conversations/{conv_id}
获取指定对话的完整消息历史
POST /api/v1/conversations
创建新对话
{ "title": "我的新对话" }
DELETE /api/v1/conversations/{conv_id}
删除对话
🧠 模型与 AI‑Groups ▼
GET /api/v1/models
获取所有可用模型列表（包括本地、Hugging Face、DeepSeek 等）
POST /api/v1/ai-groups/run
使用 AI‑Groups 多模型融合引擎生成回答
{ "prompt": "解释一下量子计算的基本原理", "models": ["deepseek-v4", "qwen-72b", "llama-3-70b"], "weights": [40, 30, 30], "math_modules": ["jacobian", "hessian", "ultra"] }
POST /api/v1/ai-groups/config
更新 AI‑Groups 配置（模型组合、权重、数学模块）
🧮 数学模块 ▼
GET /api/v1/math/modules
获取所有数学模块列表及其状态
POST /api/v1/math/toggle
启用/禁用数学模块
{ "module": "hessian", "enabled": true }
POST /api/v1/math/params
设置数学模块参数（如 Jacobian 阶数、Hessian 迭代次数等）
⚡ HPC‑Parallel 并行计算 ▼
POST /api/v1/hpc/start
启动 HPC 引擎（并行会话、Redis 缓存配置）
{ "parallel_sessions": 20, "queue_size": 5000, "cache_backend": "redis", "redis_url": "redis://localhost:6379/0" }
POST /api/v1/hpc/batch
提交批量任务（.env 格式）
{ "env_content": "SESSION_NAME=my_batch\nQUESTION_1=什么是 AI？\nQUESTION_2=解释数据主权", "max_windows": 4 }
GET /api/v1/hpc/status
获取 HPC 引擎状态（活跃会话、队列、缓存连接等）
POST /api/v1/hpc/stop
停止 HPC 引擎
📎 RAG 检索增强生成 ▼
POST /api/v1/rag/upload
上传文档（PDF, DOCX, TXT, CSV, JSON）到 RAG 索引
multipart/form-data 格式，字段名: file
POST /api/v1/rag/search
语义检索文档库
{ "query": "如何部署 CrownStar 到内网？", "top_k": 5 }
GET /api/v1/rag/documents
获取已索引的文档列表
DELETE /api/v1/rag/clear
清空所有 RAG 数据
🤝 实时协作 ▼
POST /api/v1/collab/session
创建协作会话
{ "title": "项目讨论", "creator_id": "user123" }
POST /api/v1/collab/session/{session_id}/join
加入协作会话
POST /api/v1/collab/session/{session_id}/message
发送协作消息
{ "user_id": "user123", "content": "我认为我们应该采用这个方案" }
GET /api/v1/collab/session/{session_id}
获取会话状态（参与者、消息、打字状态）
POST /api/v1/collab/session/{session_id}/leave
离开协作会话
⏰ 工作流自动化 ▼
POST /api/v1/workflow
创建工作流（定时任务或事件触发）
{ "name": "每日报告", "type": "scheduled", "schedule": "0 8 * * *", "query": "生成本日数据摘要", "action": "email", "email_recipient": "admin@company.com" }
GET /api/v1/workflow
获取所有工作流
POST /api/v1/workflow/{workflow_id}/run
立即执行工作流
DELETE /api/v1/workflow/{workflow_id}
删除工作流
🩺 系统与健康检查 ▼
GET /api/v1/health
检查服务健康状态（返回 200 表示正常）
{ "status": "ok", "version": "v7.12", "tier": "enterprise" }
GET /api/v1/tier/info
获取当前许可证层级信息
GET /api/v1/stats
获取系统统计（对话数、消息数、令牌使用等）
