📖 CrownStar API 文档

为源代码持有者（组织版及以上）提供的完整、交互式 RESTful API 参考

🔐 源代码用户专属 v7.12
🔑 认证方式 X-API-Key 或 Authorization: Bearer <token>
🌐 基础 URL: https://your-crownstar-server.com

💬 聊天与对话 6 个端点

🧩 核心聊天接口 ▼
POST /api/v1/chat
发送消息并获取 AI 回复（支持流式与非流式）
📥 请求体 (JSON)
{ "message": "你好，请解释一下什么是主权 AI", "temperature": 0.85, "max_tokens": 512, "top_p": 0.95, "stream": false, "model": "deepseek-v4" }
📤 响应示例
{ "id": "chat_abc123", "content": "主权 AI 是指数据主权、算法主权和计算主权完全由用户掌控的 AI 系统...", "tokens_used": 234, "model": "deepseek-v4", "created_at": "2026-08-18T10:30:00Z" }
📋 参数
参数类型必填说明
messagestring是用户输入的消息
temperaturefloat否0.0–1.0，默认 0.85
max_tokensint否最大生成 token 数，默认 512
top_pfloat否核采样参数，默认 0.95
streamboolean否是否流式返回，默认 false
modelstring否指定模型 ID，默认使用主模型
流式支持 SSE
GET /api/v1/conversations
获取所有对话列表（支持分页）
GET /api/v1/conversations?limit=20&offset=0
参数类型必填说明
limitint否返回数量，默认 20
offsetint否偏移量，默认 0
{ "conversations": [ { "id": "conv_001", "title": "产品规划", "created_at": "...", "message_count": 12 } ], "total": 42 }
GET /api/v1/conversations/{conv_id}
获取指定对话的完整消息历史
{ "id": "conv_001", "title": "产品规划", "messages": [ { "role": "user", "content": "我们需要一个新的 AI 功能", "timestamp": "..." }, { "role": "assistant", "content": "我建议采用 RAG 架构...", "timestamp": "..." } ] }
POST /api/v1/conversations
创建新对话
{ "title": "2026 年战略讨论" }
DELETE /api/v1/conversations/{conv_id}
删除指定对话及其所有消息
204 No Content
POST /api/v1/conversations/{conv_id}/messages
向现有对话追加消息（非流式）
{ "role": "user", "content": "补充一下，我们还需要考虑预算限制" }

🧠 模型与 AI‑Groups 4 个端点

🤖 模型管理 & 多模型融合 ▼
GET /api/v1/models
获取所有可用模型列表（本地、Hugging Face、DeepSeek 等）
{ "models": [ { "id": "deepseek-v4", "provider": "deepseek", "type": "online" }, { "id": "llama-3-70b", "provider": "hf", "type": "local" }, { "id": "qwen-72b", "provider": "ali", "type": "online" } ] }
POST /api/v1/ai-groups/run
使用 AI‑Groups 多模型融合引擎生成回答
{ "prompt": "解释量子计算的基本原理", "models": ["deepseek-v4", "qwen-72b", "llama-3-70b"], "weights": [40, 30, 30], "math_modules": ["jacobian", "hessian", "ultra"], "temperature": 0.7 }
📤 响应
{ "response": "量子计算利用量子比特的叠加和纠缠...", "model_contributions": { "deepseek-v4": "40%", "qwen-72b": "30%", "llama-3-70b": "30%" } }
POST /api/v1/ai-groups/config
更新 AI‑Groups 配置（模型组合、权重、数学模块）
{ "models": ["deepseek-v4", "qwen-72b"], "weights": [60, 40], "math_modules": ["ultra", "haykin"] }
GET /api/v1/ai-groups/config
获取当前 AI‑Groups 配置

🧮 数学模块 3 个端点

📐 可解释的数学增强层 ▼
GET /api/v1/math/modules
获取所有数学模块列表及其状态
{ "modules": [ { "name": "jacobian", "enabled": true, "params": { "order": 3 } }, { "name": "hessian", "enabled": false }, { "name": "ultra", "enabled": true, "params": { "super_factor": 1.5 } } ] }
POST /api/v1/math/toggle
启用/禁用指定数学模块
{ "module": "hessian", "enabled": true }
POST /api/v1/math/params
设置数学模块参数（如 Jacobian 阶数、Hessian 迭代次数等）
{ "module": "jacobian", "params": { "order": 5 } }

⚡ HPC‑Parallel 并行计算 5 个端点

🚀 高性能分布式计算引擎 ▼
POST /api/v1/hpc/start
启动 HPC 引擎（并行会话、Redis 缓存配置）
{ "parallel_sessions": 20, "queue_size": 5000, "cache_backend": "redis", "redis_url": "redis://localhost:6379/0", "session_ttl": 3600 }
POST /api/v1/hpc/batch
提交批量任务（.env 格式）
{ "env_content": "SESSION_NAME=my_batch\nQUESTION_1=什么是 AI？\nQUESTION_2=解释数据主权", "max_windows": 4 }
{ "batch_id": "batch_123", "windows": [ { "id": "window_01", "question": "什么是 AI？", "status": "running" } ] }
GET /api/v1/hpc/status
获取 HPC 引擎状态
POST /api/v1/hpc/stop
停止 HPC 引擎
GET /api/v1/hpc/batch/{batch_id}
获取批量任务进度

📎 RAG 检索增强生成 4 个端点

📚 文档检索与知识增强 ▼
POST /api/v1/rag/upload
上传文档到 RAG 索引（支持 PDF, DOCX, TXT, CSV, JSON）
Content-Type: multipart/form-data · 字段名: file
{ "filename": "whitepaper.pdf", "chunks": 42, "status": "indexed" }
POST /api/v1/rag/search
语义检索文档库
{ "query": "如何部署 CrownStar 到内网？", "top_k": 5 }
{ "results": [ { "chunk": "部署 CrownStar 需要...", "filename": "deploy.md", "similarity": 0.92 } ] }
GET /api/v1/rag/documents
获取已索引的文档列表
DELETE /api/v1/rag/clear
清空所有 RAG 索引数据

🤝 实时协作 5 个端点

👥 共享工作空间与实时消息 ▼
POST /api/v1/collab/session
创建协作会话
{ "title": "产品评审会议", "creator_id": "user_123" }
POST /api/v1/collab/session/{session_id}/join
加入协作会话
{ "user_id": "user_456" }
POST /api/v1/collab/session/{session_id}/message
发送协作消息（实时广播给所有参与者）
{ "user_id": "user_456", "content": "我建议采用方案 B" }
GET /api/v1/collab/session/{session_id}
获取会话状态（参与者、消息、打字状态）
POST /api/v1/collab/session/{session_id}/leave
离开协作会话

⏰ 工作流自动化 4 个端点

🔄 定时任务 & 事件触发器 ▼
POST /api/v1/workflow
创建工作流（定时或事件触发）
{ "name": "每日销售报告", "type": "scheduled", "schedule": "0 9 * * *", "query": "生成昨日销售摘要", "action": "email", "email_recipient": "sales@company.com" }
GET /api/v1/workflow
获取所有工作流列表
POST /api/v1/workflow/{workflow_id}/run
立即执行指定工作流
DELETE /api/v1/workflow/{workflow_id}
删除工作流

🩺 系统与健康检查 3 个端点

📊 运行状态与统计 ▼
GET /api/v1/health
检查服务健康状态（返回 200 表示正常）
{ "status": "ok", "version": "v7.12", "tier": "enterprise", "uptime": "72h" }
GET /api/v1/tier/info
获取当前许可证层级信息
GET /api/v1/stats
获取系统统计（对话数、消息数、令牌使用等）
{ "total_conversations": 1250, "total_messages": 8760, "tokens_used": 2450000, "active_users": 8 }
